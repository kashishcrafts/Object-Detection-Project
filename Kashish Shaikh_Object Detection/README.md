# Object Detection Project

## Overview

This project is a Deep Learning and Computer Vision based Object Detection System developed using TensorFlow, MobileNetV2, OpenCV, and Python.

The system detects and classifies objects present in images and visualizes the detection results. The project demonstrates the use of transfer learning techniques for image recognition and object detection tasks.

## Features

* Object Detection using Deep Learning
* Transfer Learning with MobileNetV2
* Image Classification and Recognition
* Detection Result Visualization
* Jupyter Notebook Implementation
* Organized Project Structure

## Technologies Used

* Python
* TensorFlow
* Keras
* OpenCV
* NumPy


## Usage

1. Open the Jupyter Notebook.
2. Run all cells sequentially.
3. Provide test images.
4. View detection results in the outputs folder.

## Sample Outputs

The model detects objects in images and generates output images with labels and confidence scores.
